# Program: Forwarded Message Triage

**Триггер:** входящее сообщение от `telegram:7622255068` (рабочий аккаунт Вадима).

## 7 правил, выполнять по порядку

### 1. Узнай точное имя файла судна

ВСЕГДА сначала: `ls /home/apbrandom/.openclaw/workspace/vault/ships/`

Канонические имена (строго так, регистр важен):
`ATLAS_1.md`, `TISA.md`, `PRUT.md`, `TURAN.md`

Алиасы из текста → канон: «Прут», «Prut», «ПРУТ» → `PRUT`. «Tisa», «Тиса» → `TISA`. И т.д.

### 2. Не нашёл судно — задай один вопрос

Если ни одно судно/алиас в тексте не упоминается:
ответь одной строкой: `К какому судну? ATLAS_1 / TISA / PRUT / TURAN`
и СТОП. Файлы не трогай.

### 3. Определи Tier

| Tier | Ключевые слова | Действие |
|---|---|---|
| **Tier 1** | позиция, порт, рейд, прибыл, вышел, переход, ETA, статус, груз, выгрузка, погрузка, поставка, заявка, инцидент, авария | редактируй `## Текущий статус` карточки судна |
| **Tier 2** | двигатель, насос, компрессор, шильдик, серийный, производитель, модель, мощность, сертификат, спецификация, запчасть | карточку НЕ редактируй, только событие с тегом `#tech-data` |

### 4. Tier 1 — обнови только эти 4 поля

В файле `vault/ships/{SHIP}.md`, секция `## Текущий статус`, замени значения этих полей:
- `**Позиция:**` — где судно
- `**Статус:**` — что сейчас происходит
- `**Последнее обновление:**` — `YYYY-MM-DD HH:MM` (взять из сообщения или текущее)
- `**Активные заявки/поставки:**` — текущая операция

Также: `last_updated:` во frontmatter → сегодняшняя дата.
Других секций НЕ касайся. Свободный текст в секцию НЕ дописывай.

### 5. Никогда не выдумывай данные

Записывай ТОЛЬКО факты из исходного сообщения. Если в сообщении нет года постройки, тоннажа, производителя — НЕ заполняй эти поля. Лучше пустое поле, чем галлюцинация.

### 6. Создай событие

Файл: `vault/events/{YYYY-MM-DD}-{SHIP}-tier{1|2}-{topic}.md`
Пример: `vault/events/2026-05-17-PRUT-tier1-unloading-riana.md`

Содержимое:
```markdown
# {SHIP} — {topic} — {date}
**Источник:** telegram:7622255068
**Дата:** {YYYY-MM-DD HH:MM}

{полный текст пересланного сообщения}
```

Для Tier 2 — добавь в конец файла строку: `#tech-data`

### 7. Ответ в Telegram

- **Tier 1 обработан:** одна строка `✓ {SHIP}: {краткая суть}, {время}`
  Пример: `✓ PRUT: выгрузка в Риану, 22:10`
- **Tier 2 обработан:** молча, ничего не отвечать
- **Не классифицировано:** один уточняющий вопрос (см. правило 2)

Запрещено: длинные ответы, эмодзи (кроме `✓`), комментарии о содержимом, «принято», «спасибо».
